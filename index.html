Propostas de Impacto Social e Educacional

Três pilares estratégicos construídos a partir das evidências extraídas dos dados.

1. Inclusão Digital Estruturada

Criação de Polos Comunitários de Estudo com internet de alta velocidade, equipamentos para empréstimo e tutoria técnica.

Meta: Reduzir a lacuna digital em até 40% nas regiões periféricas.

2. Apoio Socioemocional & Mentoria

Rede de mentoria estudantil aliada ao acompanhamento psicossocial contínuo nas escolas públicas para mitigar a evasão.

Meta: Aumentar a retenção escolar para mais de 88%.

3. Capacitação para o Futuro

Integração de módulos de programação, análise de dados e letramento digital diretamente na matriz do Ensino Médio.

Meta: Inserção profissional no setor de tecnologia.

Pipeline de Dados em Python

Código executável para rodar a limpeza e os gráficos no Google Colab

# ==============================================================================
# PROJETO: RAIO-X DA JUVENTUDE — TRATAMENTO E ANÁLISE DE DADOS
# Ferramentas: Pandas, NumPy, Matplotlib, Seaborn
# ==============================================================================

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns

# 1. GERANDO ESTRUTURA DE DADOS SINTÉTICA (DEMONSTRAÇÃO)
np.random.seed(42)
n = 1000

df = pd.DataFrame({
    'id_jovem': range(1, n + 1),
    'regiao': np.random.choice(['Norte/Nordeste', 'Sudeste/Sul', 'Centro-Oeste'], n, p=[0.4, 0.4, 0.2]),
    'renda_familiar_sm': np.random.choice(['Ate 1 SM', '1 a 3 SM', 'Acima de 3 SM'], n, p=[0.5, 0.35, 0.15]),
    'acesso_internet': np.random.choice(['Banda Larga', 'Apenas Movel', 'Sem Acesso'], n, p=[0.45, 0.42, 0.13]),
    'horas_estudo_semana': np.random.normal(loc=4.5, scale=2.0, size=n).clip(0, 15),
    'frequencia_escolar_pct': np.random.normal(loc=85, scale=10, size=n).clip(40, 100),
    'nivel_estresse_1_10': np.random.randint(1, 11, size=n)
})

# 2. LIMPEZA E TRATAMENTO
df = df.drop_duplicates()
df['horas_estudo_semana'] = df['horas_estudo_semana'].fillna(df['horas_estudo_semana'].median()).round(1)
df['frequencia_escolar_pct'] = df['frequencia_escolar_pct'].fillna(df['frequencia_escolar_pct'].mean()).round(1)

# 3. ANÁLISE EXPLORATÓRIA DE DADOS (EDA)
renda_internet = pd.crosstab(df['renda_familiar_sm'], df['acesso_internet'], normalize='index') * 100
print("--- PORCENTAGEM DE ACESSO À INTERNET POR FAIXA DE RENDA ---")
print(renda_internet)

# 4. GERAÇÃO DE VISUALIZAÇÕES
sns.set_theme(style="darkgrid")
plt.figure(figsize=(9, 5))
sns.scatterplot(
    data=df, 
    x='horas_estudo_semana', 
    y='frequencia_escolar_pct', 
    hue='renda_familiar_sm',
    palette='Set2'
)
plt.title('Horas de Estudo Semanal vs. Frequência Escolar (%)')
plt.xlabel('Horas de Estudo Semanal')
plt.ylabel('Frequência Escolar (%)')
plt.show()
